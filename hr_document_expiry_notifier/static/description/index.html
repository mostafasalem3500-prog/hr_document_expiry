Document & License Expiry Notifier

منبّه انتهاء الوثائق والتصاريح

Never get fined for an expired Iqama, work permit or commercial registration again. Record every employee and company document with its expiry date — Odoo e-mails the responsible person automatically 90, 60 and 30 days before it expires.

Key Features | المزايا

  • Automatic e-mail reminders at 90 / 60 / 30 days — each sent once, bilingual Arabic & English
  • Colour-coded status: Valid · Expiring Soon · Critical · Expired, refreshed daily
  • Renewal-aware: change the expiry date and the reminders start over
  • To-do activity created for the responsible user at the 30-day mark
  • Employee smart button with document count and “need action” badge
  • List, Kanban, Calendar, Pivot and Graph views + ready-made filters
  • Attachments, notes and full chatter history on every document
  • Multi-company rules · HR-only access (employees can’t see others’ IDs)
  • تذكيرات بريدية تلقائية قبل الانتهاء بـ 90 و60 و30 يوماً — مرة واحدة لكل مرحلة، بالعربية والإنجليزية
  • حالة ملوّنة: سارية · تنتهي قريباً · حرجة · منتهية، تُحدَّث يومياً
  • يدعم التجديد: عند تغيير تاريخ الانتهاء تبدأ التذكيرات من جديد
  • مهمة متابعة للمسؤول تلقائياً قبل الانتهاء بـ 30 يوماً
  • زر ذكي في ملف الموظف يعرض عدد وثائقه وما يحتاج إجراء
  • عرض قائمة وكانبان وتقويم وتقارير، مع فلاتر جاهزة
  • مرفقات وملاحظات وسجل تغييرات لكل وثيقة
  • دعم تعدد الشركات، والوصول مقصور على الموارد البشرية

How it works | طريقة العمل

  1. Install the module (depends only on Employees and Discuss/Mail).
  2. Open Employees › Document Expiry and add documents with their expiry dates.
  3. Set a Responsible user — reminders go to that user (or the employee’s work e-mail).
  4. A daily scheduled action refreshes statuses and sends the due reminders. Make sure an outgoing mail server is configured.
